# 0019 — 測定 RFC: teaches 可搬性の確認実験（TS 診断リプレイ）

- 日付: 2026-08-13
- 状態: **採択（4モデル並列レビュー後の全面改稿）**
- 手法: 事前登録（4ea45cb）→ codex / agy / opencode / cursor(grok-4.6-xhigh) の攻撃 → 統合。
  **4/4 が草案の中核（Δ_TS vs Δ_XN の差分の差分と、H-差分の分岐解釈）を棄却**:
  「負けられない仮説は測定ではない。(a) tsc の床を理由に小さい Δ を予測し、出たら
  (b) 言語構造の証拠と解釈するのは事前登録された偽証」（cursor）・「言語×teaches の
  交互作用を測る実験になっていない。床の高さはむしろ新言語不要の証拠になり得る」
  （codex）・「別ベンチで得た2つのリスク差の差にすぎない」（opencode）・「課題非同型で
  DiD は完全崩壊」（agy）。**私の事前登録も H-差分の設計で負けた**（数字は出ると
  4/4 も予測したが、その数字が何も意味しないことを見抜けなかった）。
  採択版は問いを2つに割る: **可搬性**（本 RFC・TS のみ・符号のみ）と
  **言語帰属**（0020 に分離・Xenith 内アブレーション・TS 不要）

## 0. 中核の是正 — 比較をやめ、符号だけを問う

- **Δ_TS と Δ_XN の比較は全削除**。報告は TS 内の {native, native+teach} 対比のみ。
  0009 の数字は動機としてのみ引用し、いかなる比較主張もしない
- **「新言語が必要か」は本実験では答えない**。その問いに識別可能に答える設計は
  言語横断比較ではなく、**teaches を固定した Xenith 内アブレーション**である
  （3/4 が独立に同じ出口を提示）: named args 強制 off・候補提示 off 等、ラッパで
  後付け不能な言語結合部を1本ずつ落とし、どれが修復 Δ を殺すかを見る。
  落として Δ が死ねば「後付け不能な部分が効いている」の直接証拠。**0020 として登録**
- 本 RFC が答える問い: **「teaches の符号は TypeScript に移るか」** — GPT 指摘の
  前半（既存言語＋同等 protocol の基線が存在しない）にだけ、確実に答える

## 1. 手順 −1 — プロンプトのバイトから証明できるものを先に測る（cursor 採択）

LLM を1走も焼く前に、**tsc 素診断と teaches ペイロードの情報重複率を静的に測る**:

- 対象バグ族候補（未知メンバー / 名前近似 / 引数型 / 引数個数）ごとに、素診断が
  既に含む事実（期待型・個数・候補名）と teaches が足す事実（完全シグネチャ・
  メンバー表・関連 overload）を機械比較し、族別の重複率を出す
- **重複が閾値（事前登録: 追加事実 0 件）を超える族は治療対象から外す** —
  素診断が既に答えを言っている族で「効かない」を測るのは 0016 の禁じ手
  「null に走を燃やす」の再演だから
- 全族が脱落したら「tsc は既に teaches を内蔵している」を結論として記録し、
  本測定は走らせない（それ自体が GPT への回答になる）

## 2. 装置 — 対応付き診断リプレイ（codex 代案の採択）

モデルに誤らせない。**失敗は処置前に凍結する**:

- 中立スキーマ（ドメイン中立の小さな API 仕様）から TS の `lib/` と
  **バグ注入済み client** を機械生成。バグ族は手順 −1 の生存分
- 同一の壊れた client を各モデルの新規セッションへ複製し、**単発修復**（1ラウンド）。
  腕は {ts-native, ts-teach} の2腕・client×モデルごとに無作為割付
- 成功 = tsc 通過 **かつ** 動的オラクル（実行 trace で lib の対象関数が実際に
  呼ばれたことを検証 — 定数出力・再実装の抜け道封じ）
- **分母は対象診断が発火した試行のみ**（構造的型付けが誤用を黙認して診断ゼロに
  なったケースは「不発火」として別掲 — 可搬性の失敗と発火条件の失敗を混ぜない）
- 配達監査（0012）: teach 腕で実際にペイロードが載ったことを機械記録
- ts-teaches 実装: 依存は `typescript` 1本・版固定・`--ignore-scripts`・lockfile
  コミット・`--teaching=off` で素の tsc とバイト同一（0009 の自己検証）

## 3. 規模と判定規則（事前登録）

- 4 スキーマ × 生存バグ族（≤4）× 7 モデル × 2 腕 ≤ **224 単発走**
  （草案のマルチラウンド 84 走より安く、失敗分母・誤り構成・発火条件を固定できる）
- 判定はペア比較: 同一 client・同一モデルの {native, teach} 対で勝敗を数え、
  **符号検定（両側 α=0.05）＋効果量（ペア勝率）を報告**。クラスタ＝スキーマ×モデル。
  全体プールの率差は参考値としてのみ併記
- **H-可搬-TS（唯一の仮説）**: teach 腕がペア比較で native に勝つ。
  予測: 成立（私・4レビュアーとも成立側、主観 60〜75%）
- 反証の分岐も事前に: 不成立なら「tsc の床の上では teaches の限界価値が小さい」
  であり、Xenith でも同じかは 0020 のアブレーションでしか答えない。
  **どちらの結果からも「新言語が必要/不要」への跳躍は書かない**

## 4. 入れないもの

- Δ_XN との比較・言語優劣・「新言語が必要」方向の一切の解釈（0020 の領分）
- Xenith 腕の再走（比較しないので不要）
- 手順0（LLM で失敗分布を採る工程）— リプレイ設計はバグを注入するので不要。
  静的な手順 −1 が代替
- 新規 TS 課題でのマルチラウンド agent 測定・Rust 基線・LSP・tsserver プラグイン

## 5. 判定（2026-08-16・224セル走行後に追記）

**H-可搬-TS: 成立。** 不一致ペア **19/19 が teach 側**（両側符号検定 p = 3.8×10⁻⁶・
ペア勝率 100%）。回答が成立した5モデル全てで teach 腕は 16/16 緑
（native は 11〜14/16）。集計は `bench/baseline/ts-teaches/results/`（生 JSONL・
summary.md・analyze.mjs・版数記録）。

- **効果の在処は手順−1 の予測と一致**: teach 勝ち19の内訳は 2554（引数個数）が
  **17**、2345 が 2。tsc の「Expected 3 arguments, but got 2」は個数しか言わず、
  モデルは欠けた引数の**型**を当てられない（boolean の位置に string/number を入れて
  TS2345 で死ぬ）— そこに完全シグネチャ1行が着地する
- **新規事実の量だけでは効果を予測しない**: 2339/2551 は新規事実率が最高
  （4/4・3/4）だったが、client 側の文字列ラベル（"currency=" 等）が意図の
  **代替回復経路**になり、ほぼ全ペアが両腕緑。効果は
  **「新規事実 × 代替回復経路の不在」**に宿る — 次の計器設計の変数はこれ
- 別掲: grok は 32/32 タイムアウト（4.6 ヘッドレス死・対から除外）。
  nemotron は 12 ペアがコード無しの物語回答（腕対称の脱落・ITT では 5/16→8/16 と
  同方向）。中立ディレクトリに過去キャンペーンの残骸を発見し走行初期に掃除
  （起動前掃除を今後の標準とする — campaign-notes.txt）
- **事前登録どおり、「新言語が必要/不要」への跳躍は書かない。** 言えるのは:
  teaches の機構（誤り地点への正確な事実の自発添付）は tsc にそのまま移植でき、
  そこでも同符号で効く。GPT 指摘の前半（既存言語＋同等 protocol の基線が無い）は
  これで塞がった。言語結合部の帰属は 0020（アブレーション）の領分

## 6. 却下された草案要素（記録）

- **Δ_TS vs Δ_XN の「差分の差分」**（4/4）— 別課題・別年次・別治療強度・別診断床の
  単差の引き算であり、DiD の同一ユニット仮定を満たさない
- **H-差分と分岐解釈**（4/4）— 交絡の全てが同方向に働き反証不能。予測どおりの数字が
  出ることと、その数字に意味があることは別（agy は逆符号 Δ_TS ≥ Δ_XN すら予測:
  「暗闇に投げ込まれた照明弾」効果）
- **新規 TS 課題 + 失敗ラウンド条件付け**（agy/codex/opencode）— 課題×言語の完全交絡、
  post-treatment 選択、「必ず誤る」の非保証
- **歴史値 0009 との比較**（codex/opencode/cursor）— モデル snapshot・ハーネス・時期が
  言語差に混入する歴史的対照
- **手順0による治療の適応的選抜**（codex）— researcher degrees of freedom。
  静的重複測定（手順 −1）に置換
