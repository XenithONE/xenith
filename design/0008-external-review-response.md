## 1. 受理した P0（実装が仕様の主張を裏切っている箇所）

### P0-1 — クロージャが効果検査の嘘をつける

0007 D3 は「関数値は存在しない」と宣言したが、**パーサはラムダ・`async`・`.await`・
関数値を受理し、検査器はラムダ型に空の効果集合を与える**（check.rs のコメント自身が
推論の未実装を認めている）。IO 権能を捕獲したクロージャが型上は純粋な関数として
外へ出られる。効果システムの中心的主張への直接の反例である。

**決定（codex の提案どおり）**: ラムダ式・`.await`・`async fn`・`for`・関数型注釈を
**検査器で拒否**する。パーサは受理を続ける（total parser の方針どおり、拒否は診断で行う）。
安定コードを1つ追加し、explain には「未出荷の構文である」ことと代替
（名前付き関数 / `while` + `len` + `get`）を書く。クロージャ効果推論・効果多相・
async の効果規則は**独立 RFC**（0004 の実装時）まで封印する。
中途半端に通すことが最も危険、という codex の判定を全面採用。

### P0-2 — `match` の網羅性が仕様上だけ存在する

field-guide は「`match` は網羅的でなければならない」と断言するが、実装は
実行時トラップ（interp.rs「exhaustiveness is on you until XN5xxx lands」）。
バックログに積んであった XN5xxx を**今**実装する。

**決定**: XN5001「網羅されていない `match`」を実装する。対象: `Bool`・`Unit`・
enum（payload 付き変種は部分パターンへ再帰）・struct パターン・ワイルドカード/束縛・
OR パターン。**ガードつき腕は網羅性に寄与しない**。`Int`/`String`/`Float`/`Char` の
スクルーティニは列挙不能なのでワイルドカード（または束縛）を要求する。
診断には不足している証人（例: `Rank.Gold`）を最低1つ載せる。

## 2. 受理した実装課題（MCP / ワイヤ）

- `line`/`column` の `u64 as u32` 無検査キャスト → `u32::try_from` で拒否（実在確認済み）
- MCP が任意パスを読み、`fmt write=true` で書ける → `--workspace-root` を導入し、
  canonicalize 後に root 外を拒否。フォーマッタの書き込みは一時ファイル + rename の
  原子的置換にする
- ワイヤ JSON のトップレベルに `schema_version` を追加

## 3. 受理した実験上の指摘（次の測定の設計）

分離パイロットの「query 因子 0」は機構の敗北ではなく**不作動**だった
（失敗50ラウンド中 goals 発話2回 — README に記録済み）。codex も独立に同じ診断。

**決定**: 次の測定は**全4腕に同一の文**「判断できない式は推測せず `??` を置いてよい」を
入れ、query 利用可否だけを差にする。加えて、ホールを書かなくても使える能動 API
（`producers-at` / `methods-of` / `signature`）は候補改良と併せて将来の RFC とする
（codex の「モデルが作法を知らなくても支援できる形が製品として強い」を採用）。

## 4. 受理したがこの波ではやらないもの

- 候補生成の「同型変数の自動充填」が曖昧さを隠す問題 → 曖昧なら `??` を残す方針で
  候補改良 RFC に含める（codex / 0007 レビューの agy と同旨）
- 機能表面の機械可読な一元管理（feature × parser/checker/runtime/documented/tested の表を
  CI で照合）→ P0-1 の検査器拒否で「受理するが未文書」の乖離自体は塞がる。表と CI 照合は
  次のドキュメント波で
- モジュール・高階関数・並行性（0004 実装）→ codex の推奨順序どおり、上記が塞がってから

## 5. 順序（codex の推奨を採用）

1. ラムダ・関数値・async・for を検査器で拒否
2. `match` 網羅性検査（XN5001）
3. MCP の数値変換・workspace 制限・schema_version・原子的書き込み
4. 全腕同一のホール指示で分離実験を再実施
5. 候補ランキングと能動クエリの改良
6. module・高階関数・並行性
