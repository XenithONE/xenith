Xenith, running in your browser

The Xenith compiler and its interpreter, cross-compiled to WebAssembly and running on this page. Nothing is sent anywhere: the parser, the type checker and the tree-walking interpreter are all in the module your browser just downloaded.

Children of spawn run on the sequential executor here — the browser has no threads. The compiler tests both executors against each other byte for byte (design/0017 §5), so this is the same program you would get from xenith run.
